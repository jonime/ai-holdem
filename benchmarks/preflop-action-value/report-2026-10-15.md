# Offline preflop action-value report — 2026-10-15

The evidence supports a separate **benchmark-only preflop strategy experiment**, prioritizing medium-difficulty six-seat KK opening folds and hard-difficulty QQ opening folds. It does not support a universal 3-BB opening rule or production promotion. Sampling-budget changes materially affect several findings.

## Design and completion

Completed 180 groups and 54,000 paired seed blocks: 45,000 primary blocks at 100 equity samples and 9,000 sensitivity blocks at 1,000 samples. 0 blocks were excluded. Exact first-action duplicates shared rollouts; 184,500 continuations completed after deduplication within each seed block. No provider requests were made.

There are 5,000 distinct conditioned deals (five holdings × two nodes × 500 seeds). The sensitivity run reuses the first 1,000 of those deals. Policies, difficulties and actions reuse deals deliberately; their repetitions are not independent samples. Hero holdings use one suit representative each, and independent games start at hand number 1 without separately varying the Rules frequency hash. Initial action counts describe fixed inputs rather than a production mixture. See [the guide](README.md) for the frozen design and assumptions.

Action values measure terminal hero stack minus stack immediately before the tested decision, in BB. Posted blinds are sunk costs. Values include all subsequent engine actions under the stated continuation policies, with no rake. These are conditional simulations, not GTO values or estimates against real human/provider opponents.

## Interpretation and next action

**Prioritize the medium KK opening fold.** At six-seat UTG, calling and raising both beat the baseline fold against all three controls at both budgets, including the matched first-100-seed comparison. Against frozen Rules, the 3-BB raise gained 26.58 BB [19.34, 33.71] per conditioned hand in the primary run and 31.59 BB [15.35, 46.81] at 1,000 samples. These are values conditional on being dealt KK, not a whole-policy BB/hand score. Hard-difficulty QQ also retained positive raise-versus-fold intervals across all three controls and matched budgets. Medium QQ and both AK classes have wider, zero-crossing frozen-opponent sensitivity intervals. These findings prioritize an experiment; they do not choose an optimal raise size or establish that raising beats calling.

**Treat AA's primary fold as a sampling-budget effect.** Medium six-seat AA folds at 100 samples but calls at 1,000; the earlier improvement report's 5,000-sample trace also calls. Against frozen Rules, the matched raise advantage changes from +39.10 BB [24.48, 53.74] to -10.19 BB [-22.02, 2.45] as the baseline changes. This is not evidence that production folds AA in this opening situation. Heads-up AKs initial actions also change with the budget. Even unchanged first actions can lead to different continuation values: medium six-seat AKo calling against the aggressive policy loses 81 BB on every matched 100-sample deal, but returns +56 BB [8, 110] at 1,000 samples. A blanket “never fold premiums” patch is not justified by these results.

**Retain the unfavorable heads-up controls.** The primary 3-BB raise loses against frozen Rules with easy QQ (-3.58 BB [-6.64, -0.69]) and against the aggressive policy with AKo (easy: -2.22 [-3.85, -0.74]; medium/hard: -1.18 [-2.44, -0.07]). The corresponding 1,000-sample results are inconclusive for QQ and exactly tied for AKo. Together with the six-seat results, this rules out claiming a robust universal opening-size improvement from this study.

**Next action: design an isolated preflop candidate, then evaluate it separately.** Start with the KK/QQ opening decisions above, validate fixed decisions at the production 5,000-sample budget, and test the candidate against held-out deals and broader hand, position, seat-count and stack coverage before any promotion decision. Preserve call/raise alternatives and all unfavorable opponent groups; do not lower expectations to make folds disappear or combine the candidate with the seed rewrite. This study supplies conditional action-value evidence, not a newly discovered opponent-count or call-price defect. Rules seed normalization, Jev normalization and LLM normalization remain deferred, and no further paid calls are scheduled.

Intervals use 2,000 whole-seed percentile bootstrap resamples. They describe Monte Carlo variability under these explicit policies and fixed holdings; they do not account for uncertainty about opponent realism. The many correlated comparisons are unadjusted for multiplicity. No cross-group chip averages or claims of solver optimality are made. A tested 3-BB raise is one candidate size, not an optimized sizing policy. Both simulation budgets are below the production default of 5,000 equity samples, so promotion would require validating that additional gap.

## Verification and provenance

Focused mechanics tests cover current production context equivalence, hidden-card isolation, deterministic pairing, legal actions, deduplication, decision-point stack accounting, split all-ins, source-freeze rejection, credential-free workers and whole-block exclusion. `npm run check` passed all 1,909 tests, lint and strict TypeScript. No Next.js routing/rendering/environment/deployment code changed; build, SQL and browser verification were not required.

Every source hash was verified before and after the frozen run. The offline run resumed only matching completed-group checkpoints after an interruption. A supplementary offline scheduler processed the same frozen groups from the opposite end of the allocation, allowing six concurrent isolated workers. Identical duplicate checkpoints are deduplicated, never counted as additional samples. The standard command reproduces the experiment with three workers; scheduling does not affect seeded outputs. Earlier audit/improvement evidence was preserved unchanged.

`npm run benchmark:preflop-action-value:analyze` reconstructs all group summaries from saved evidence without simulations or inference. Matched sensitivity summaries apply the same frozen `summarize` function to each primary group’s first 100 rows and its 1,000-sample group; deck hashes and seed IDs are checked pairwise. Production selection, context, strategy, providers and persistence remain unchanged.
